MAKE THE CHOICE EASY

Which edition should you start with?

I work solo with Codex, Claude Code, or Antigravity.

Desktop is the right starting point for individual, local workflows. You can configure MCP access using Scrawl’s local extension or connection settings.

I want to connect through ChatGPT or Gemini in the cloud.

Choose the Server edition hosted over HTTPS for remote MCP connections, and verify that your specific AI client, plan, and version support custom remote MCP connectors.

I want to collaborate with my team or run a 24/7 bot.

Choose the Server edition for multi-user access and real-time collaborative editing. For 24/7 automations, pair Scrawl Server with a bot or automation service running in its own always-on environment.
